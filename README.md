## 🧠 Engineering Philosophy

- **Keep it simple** — prefer a modular monolith over unnecessary microservices.
- **Design for maintainability** — Clean Architecture, dependency injection, repository pattern and clear separation of concerns.
- **Automate repetitive work** — turn complex, multi-step workflows into reliable automated processes.
- **Own the full lifecycle** — from design and implementation to testing, deployment and monitoring.
- **Build for production** — reliability, observability and operational simplicity matter.

## ⚙️ What I Build

- **Automation systems** — bots, automated workflows, task orchestration and scheduled jobs.
- **Backend applications** — modular APIs, background workers, queues and business logic.
- **Full-stack web applications** — React interfaces integrated with production backend services.
- **Infrastructure & observability** — containerized services, CI/CD, monitoring and production operations.

## 🤖 AI-Assisted Engineering

AI is part of my development workflow, not a replacement for engineering judgment.

I use **Claude Code** as my main tool, alongside **ChatGPT / Codex**, to accelerate implementation, refactoring, debugging and code review.
I combine AI-assisted development with clear architecture, automated testing and human accountability for everything that goes to production.
